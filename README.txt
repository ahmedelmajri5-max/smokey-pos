Smokey POS Web App

طريقة الاستخدام على الهاتف:
1. ارفع مجلد Smokey_POS_Drive إلى استضافة static مثل Netlify أو GitHub Pages.
2. افتح الرابط من متصفح الهاتف.
3. من المتصفح اختر Add to Home Screen / إضافة إلى الشاشة الرئيسية.
4. بعد أول فتح، التطبيق والبيانات تبقى داخل الهاتف ويمكن فتحه حتى لو الكمبيوتر طافي.

ملاحظة:
Google Drive ليس استضافة تطبيقات، وقد يفتح HTML كمعاينة فقط. للحصول على تطبيق يفتح كرابط ويتثبت على الهاتف ويعمل بدون إنترنت، استخدم Netlify أو GitHub Pages.
